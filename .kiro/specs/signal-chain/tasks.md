# Tasks: signal chain (The Wire)

Generated by Kiro from `requirements.md` and `design.md`. Ordered so the seeded
channel, framing, CRC and the loopback transport land **before any audio/DSP
work**: the pure byte-and-event path is proven first, then FSK modulation, then the
hardware-touching acoustic transport last.

**Invariant for every task:** the existing `src/engine/engine.test.ts` suite stays
green. New code goes only in `src/channel/`, `src/modem/`, `src/transport/`, plus
engine-side replay tests; nothing in these tasks edits `src/engine/reducer.ts`,
`audience.ts`, `scenario.ts` or `types.ts` in a way that changes current behaviour.

**Done means:** `pnpm typecheck`, `pnpm test`, `pnpm build` all pass, and the task's
own tests (example + property) pass. Record every measured number (bit-error rate,
recovery rate) in `docs/RESULTS.md`. Mark an item `[x]` only on confirmed re-run
evidence, never on an assertion.

## Phase A — pure byte and event path (no audio)

- [ ] **A1. Seeded PRNG.** Implement `src/channel/prng.ts`: uint32-seeded
  deterministic stream (`nextUint32`, `nextFloat`, `nextBool(p)`), no `Math.random`
  / `Date.now`. Tests: `prng.test.ts` (known-seed vector) and `prng.prop.test.ts`
  (same seed ⇒ identical stream; stream reproducible after re-seed). _Backs the
  determinism in P4._

- [ ] **A2. CRC-16.** Implement `src/modem/crc.ts` over a byte array (polynomial
  chosen per design open point 2, recorded in `docs/RESULTS.md`). Tests:
  `crc.test.ts` (fixed check value) and `crc.prop.test.ts` — **P2 support**: any
  single-bit change to the input changes the CRC.

- [ ] **A3. Framing + parse.** Implement `src/modem/frame.ts`: `frame(payload)` and
  `parse(bytes)` (preamble + sync + length + payload ≤64 + CRC-16); typed
  `PayloadTooLargeError`; bad CRC → `garbled` parse result, never a silent fix.
  Tests: `frame.test.ts` (Req 1.3 typed-error example; empty + 64-byte boundaries)
  and `frame.prop.test.ts` — **P1** (round-trip, Req 1.1) and **P2** (single-bit
  flip ⇒ garbled, Req 1.2).

- [ ] **A4. Simulated channel.** Implement `src/channel/channel.ts`: applies delay,
  drop, bit-flip and collision from the PRNG per channel profile and send times;
  emits `received | garbled | collision`. Tests: `channel.test.ts` (Req 3.2
  overlap ⇒ collision to both, deliver neither) and `channel.prop.test.ts` — **P4**
  (determinism, Req 3.1) and **P5** (no delivery before send + min delay, Req 3.3).

- [ ] **A5. Transport interface + loopback + scripted.** Define
  `src/transport/types.ts` (`Transport`: `send(frame)` + `received|garbled|collision`
  events). Implement `src/transport/loopback.ts` (two tabs via `BroadcastChannel`,
  impairments from the A4 channel) and `src/transport/scripted.ts` (solo partner,
  fixed send schedule through the same channel). Tests: `loopback.test.ts` and
  `scripted.test.ts` drive the channel core with a `BroadcastChannel` test double;
  assert Req 4.1 (both satisfy one interface) and the half-duplex decode-suppression
  state (Req 2.3) at the transport level.

- [ ] **A6. Engine integration + replay.** Shape channel events so a transport hands
  the engine exactly one appended event per outcome with sim-time, sender,
  recipient, outcome (Req 5.1). Tests: `src/engine/replay-channel.test.ts`
  (one event per outcome) and `src/engine/replay-channel.prop.test.ts` — **P6**
  (Req 5.2: replay reaches the same state, touches no transport — transport double
  throws if called). **Confirm `src/engine/engine.test.ts` still passes.**

_Checkpoint: Phases A1–A6 give a fully testable Wire with zero audio. The loopback
and scripted transports are playable in two tabs / solo here._

## Phase B — FSK modulation (pure DSP, no hardware)

- [ ] **B1. FSK modulate/demodulate.** Implement `src/modem/fsk.ts`: binary FSK,
  continuous phase, Goertzel/quadrature per symbol, clock recovery from the
  preamble; pure functions over `Float32Array`. Tests: `fsk.test.ts` (known
  tone/sample vectors) and `fsk.prop.test.ts` — **P3** (round-trip at 44.1 and
  48 kHz, Req 2.1).

- [ ] **B2. Noise-tolerance trial.** Fixed-seed statistical test: 200 frames at
  ≥12 dB SNR with seeded white noise; assert ≥95% recovery (Req 2.2) and record the
  measured rate in `docs/RESULTS.md`. Tune tones/baud/sync by measurement, logging
  each change and its bit-error-rate result.

## Phase C — acoustic transport (hardware; last)

- [ ] **C1. AudioWorklet shell + acoustic transport.** Implement
  `src/transport/acoustic.ts` over Web Audio: thin worklet shell around the pure
  B1 demodulator; half-duplex (no decode while transmitting, Req 2.3). Report
  measured airtime and signal level as event metadata (Req 4.3); unit-test the
  metadata-shaping function with synthetic inputs.

- [ ] **C2. Permission fallback.** Mic denied/unavailable → fall back to loopback or
  scripted and surface the reason in text (Req 4.2). Example test on the selection
  path with a mocked `getUserMedia` rejection.

- [ ] **C3. Manual audio checks.** Real speaker→mic at 1 m between two laptops:
  record steps, recovery rate and pass/fail in `docs/RESULTS.md`. Per modem
  steering, acoustic mode is time-boxed to Nov 21; if it is not reliable, switch the
  acoustic transport to MIT-licensed `ggwave` behind the same `Transport` interface
  and say so in the write-up. (Requires asking before adding the dependency.)
