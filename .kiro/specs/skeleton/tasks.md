# Implementation Plan: skeleton (Hindsight kit and workspace)

## Overview

Generated by Kiro from `requirements.md` and `design.md`. This is a **move, not a
rewrite**. The seams that the requirements force (decoupling the channel from the
modem, generic participants, scenario content out of the engine) are applied **in
place in the flat repo first**, so every later move is relocation plus import
rewrites and nothing else.

**Baseline:** 100 passing tests in the flat repo (record the exact count from
`pnpm test` in the first task and use it as the floor). `src/engine/engine.test.ts`
keeps its name and its assertions for the whole plan; it only changes location and
import lines.

**Done means, for every task:** `pnpm typecheck`, `pnpm test`, `pnpm build` all pass
at the root, the test count is at or above the previous task's count (a task that
deletes a test says which and why), and the task's own new tests pass. Property
tests use `fast-check`, run at least 100 iterations, live in `x.prop.test.ts`, and
carry a `Feature: skeleton, Property N` comment. Mark an item `[x]` only on
confirmed re-run evidence, never on an assertion. Move files with `mv`, not `git mv`
(the developer stages and commits by hand).

**Not in this spec:** modem and transport behavior (see `signal-chain`), console UI
(`consoles`), the real replay view (`seance-replay`), Night Desk content
(`night-desk`).
