# /kiro-log

Append one entry to `docs/KIRO-USAGE.md` for the work just done in this session. Use only facts from this session:

- date, Kiro surface (IDE / CLI / Web / Crew), feature used (spec, hook, steering, custom agent, workflow, MCP, power, PBT, vibe)
- what was asked, what Kiro produced, credits and time if shown
- one thing that went wrong or surprised us and how it was resolved
- evidence: file paths, test names, counterexamples

Keep it under 8 lines. Never invent numbers.
